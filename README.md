# 3D Minecraft Web MVP

HTML5 / CSS3 / JavaScript (Three.js) で作られた、ブラウザ上で軽快に動作する3Dマインクラフトのプロトタイプ（MVP）です。

## 🌐 公開URL (GitHub Pages)
https://udedu-maker.github.io/app-prottype/

## ✨ 主な機能
- **3Dボクセルワールド**: 草、土、石、原木、葉、レンガ、木板などのブロックで構成された丘陵地形
- **破壊＆設置システム**:
  - 左クリック: ブロックの破壊（専用の破壊音＆飛び散るパーティクル効果）
  - 右クリック: 選択中ブロックの設置（スタック防止判定つき）
- **一人称視点＆リアルな物理演算**:
  - ポインターロックによるマウス視点移動
  - WASD移動、ジャンプ、ダッシュ（Shiftキー）
  - プレイヤーの境界ボックス（AABB）による正確な衝突・接地判定
- **マイクラ風プロシージャルテクスチャ**:
  - 外部画像不要！Canvas APIにより16x16ピクセルアート風テクスチャを自動生成
- **自前シンセサイズ効果音 (Web Audio API)**:
  - 外部音声ファイル不要！破壊音、設置音、ジャンプ音、足音をブラウザ内でリアルタイム合成
- **マイクラ風ホットバー**:
  - 画面下部のスロット（1〜7キーまたはマウスホイールで切り替え）
- **パフォーマンス最適化**:
  - 地中などの不可視ブロックを自動カリングし、低スペック端末でも60FPSを維持

## 🎮 操作方法
| キー / 操作 | アクション |
| :--- | :--- |
| **W, A, S, D** | 前後左右に移動 |
| **Space** | ジャンプ |
| **Shift** | ダッシュ（高速移動） |
| **マウス移動** | 視点操作 |
| **左クリック** | ブロックを破壊 |
| **右クリック** | ブロックを設置 |
| **1 〜 7 / ホイール** | 手持ちブロックの切り替え |
| **ESC** | メニューに戻る（マウスカーソル解放） |
